## ✅ 이번주 진행사항

### 🔹 개발상황   

모델 성능 안정화: label_map 기반 fine-tuning 및 cross-entropy loss를 활용한 학습 안정화

의미 기반 예측 구현: 실제 CSV 컬럼 임베딩을 통해 특정 의미(예: 사건개요)와의 유사도 계산

예측 성능 평가: 공공데이터 기반 CSV 파일을 활용한 CTA 예측 정확도 실험 및 성능 비교 분석

사용자 인터랙션 기능 개선: 노드 검색 기능 오류 수정 및 클릭 시 노드 정보가 표시되지 않던 문제 해결

### 🔸 팀 공통사항

- 프로젝트의 핵심 주제와 데이터 처리 방식, 시스템 구조 등을 효과적으로 전달할 수 있도록 내용 구성과 시각적 표현에 집중했음



<br>

#### 💡 이지훈 (수저완료)

- KoBERT 기반 모델과 학습된 데이터셋을 이용하여 컬럼 의미 분류 모델 구조를 정립하고, 전처리된 학습 데이터를 이용해 텍스트임베딩 실행
- fine-tuned 모델은 기존 label_map(성명, 나이, 주소 등)을 기준으로 학습되었으며 cross-entropy loss를 기반으로 학습 안정화함.
- 학습된 모델을 활용해 실제 CSV 파일의 컬럼별 값을 임베딩하고, 특정 의미(예: 사건개요)와의 확률적 유사도를 계산함.
- 공공데이터 기반의 다양한 CSV 파일에 대해 CTA 예측 정확도를 실험적으로 비교 분석함.
- 레이블링 된 데이터들의  예측 성능이 우수하게 나타났으며, 불용어가 많거나 형식이 다양한 데이터에서도 의미 추론이 정확하게 수행됨.
